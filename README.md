# WorkĐi - Digital Nomad Cafe Finder

WorkĐi is a mobile-first platform designed to help Digital Nomads in Vietnam find the best work-friendly cafes.

## Features

- **Mobile-First Design**: Optimized for mobile usage.
- **Cafe Search**: Find cafes with specific criteria like Wi-Fi speed, power outlets, and quietness.
- **Cafe Details**: View work-friendly scores, ratings, and amenities.
- **Interactive**: Easy navigation and map access.

## Tech Stack

- **Framework**: Next.js 14+ (App Router)
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Language**: TypeScript

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) with your browser.
